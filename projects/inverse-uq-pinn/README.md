# inverse-uq-pinn

**Idea 2 — Inverse reconstruction with uncertainty.**

via the differentiable solver, with calibrated uncertainty and an identifiability
analysis (what can/can't be recovered, and how confidently). FEM oracle supplies
ground-truth parameters.
